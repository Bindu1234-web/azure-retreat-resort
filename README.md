# Azure Retreat | Luxury Resort & Spa

A modern and responsive luxury resort landing page designed to provide a premium and visually appealing user experience.

## 🌴 Project Overview

Azure Retreat is a responsive resort website created as a Web Developer assignment. The website includes a luxury hero section, resort information, amenities, gallery, enquiry form, call-to-action sections, and footer.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Luxury resort hero section
- About the resort section
- Amenities and activities
- Image gallery with lightbox
- Contact and enquiry form
- Call-to-action sections
- Responsive navigation menu
- Form validation
- Smooth scrolling
- Scroll reveal animations
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons
- Google Fonts
